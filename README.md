# AS Bon Sauveur — V22

Application de gestion de l'Association Sportive du Bon Sauveur.

## V22

- Connexion par code PIN pour les enseignants et éducateurs.
- Compte administrateur de secours par e-mail.
- Commandes et inscriptions enregistrées immédiatement, puis paiement contrôlé manuellement.
- Contrôles d'accès côté base, journal d'audit, limitation de débit et politique de conservation.
- Dépendances JavaScript servies localement, sans traqueur ni police distante.
- Notice : [confidentialite.html](./confidentialite.html)

La purge de conservation est fournie mais n'est pas planifiée automatiquement avant validation des durées par le responsable de traitement.
